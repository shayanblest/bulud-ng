# Catalog, forms and reusable chat audit — 2026-10-21

Prior foundation audit remains applicable. Read current base/library and Angour ticket message-list, shared pipes, and design tokens before implementation.

| Area                  | Finding                                                                                                                                                      | Change / verification                                                                                                                                                                                                                                        |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| General pipes         | All original Angour pipes are already transferred; missing common locale number/currency/percent, relative time, duration, safe truncation/fallback examples | Add pure standalone utilities with bounded Intl caches and explicit relative-time clock input; reuse Angular built-in pipes for built-in functionality rather than duplicating them                                                                          |
| Badge                 | Angour preset is outlined on surface, radius 6px                                                                                                             | Filled semantic button-like colors, control radius and weight; preserve noninteractive badge semantics, dismiss button keyboard behavior and token overrides                                                                                                 |
| Required labels       | Forms literally include `*`; no reusable automatic required indicator                                                                                        | Add accessible form-label component tied to AbstractControl events/required validators, with explicit override for custom/opaque validators; replace literal stars; required state remains visible even after valid entry                                    |
| Chat                  | Angour message-list mixes two-sided theme UI with ticket/auth/receipt APIs                                                                                   | Extract controlled standalone chat, incoming/outgoing bubbles mirrored through logical layout, safe text, timestamps, statuses, attachment action output, composer validation, loading/error/disabled/empty; application owns transport and acknowledgements |
| Navigation            | Unified Demo and only grouped legacy pages                                                                                                                   | Remove Demo navigation, overview explains installation/loading/pages/components; lazy route per feature with live example, API guidance and copyable sample code; nested component submenus                                                                  |
| Theme toggle          | Secondary button                                                                                                                                             | Existing Angour switch with accessible localized label and preserved preference                                                                                                                                                                              |
| Packaging/performance | Secondary entries, explicit CSS, 300kB initial budget                                                                                                        | Retain; no dependency upgrades/additions; production build, unit/E2E, isolated packaged consumers, size gate, Lighthouse                                                                                                                                     |

References: https://angular.dev/guide/templates/pipes (pure transformations), https://angular.dev/api/forms/AbstractControl (hasValidator/events). “Newest” means modern standalone APIs on the project's compatible Angular version, not an unrequested framework/dependency upgrade.
