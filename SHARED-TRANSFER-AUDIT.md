# Angour shared transfer audit — 2026-10-21

Audited source: `angour/libs/shared/{ui,services,utilities,models}` and references in applications. Destination already has dropdown, pagination, datepicker, dialog, tabs, accordion, checkbox, switch, radio, button and badges. Preserve these and their validation/accessibility improvements.

| Source                                                        | Decision / destination                                                                                                            | Required checks                                                                    |
| ------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| utilities/dataset.ts + ListRequestModel                       | `bulud-ng/query`: pure typed URL/list conversion, filter parse/build; injectable facade, no Router dependency                     | repeated params, malformed page, escaping, prototype keys, immutable round trips   |
| UI `_tables.scss`, table-popup, list screens                  | `bulud-ng/table`: semantic table, sort, paging, projected cells/details, empty/loading/error                                      | keyboard, row identity, server/local mode, RTL/dark, theme precedence              |
| advanced-select, pagination, modal, tabs, filter-switch       | Existing Dropdown/Pagination/Dialog/Tabs/Switch                                                                                   | No duplicate legacy implementations                                                |
| otp                                                           | `bulud-ng/otp`: native single OTP input, CVA/Validator, localized digits, autocomplete                                            | invalid/required/length, paste, disabled, reset; no timed focus jumps              |
| file-upload                                                   | `bulud-ng/file-upload`: native file input, CVA/Validator, type/size/count rules                                                   | reset, disabled, errors; files never automatically sent                            |
| tooltip                                                       | `bulud-ng/tooltip`: focus/hover/Escape, describedby preserving caller tokens                                                      | name, dismissal, keyboard, theme                                                   |
| alert/loading-page                                            | `bulud-ng/feedback`: projected alert + signal notification store/outlet, explicit removal, no HTML injection                      | live regions, IDs, per-app scoped store                                            |
| star-rating                                                   | `bulud-ng/rating`: native radio group + CVA                                                                                       | keyboard, disabled, required, integer bounds                                       |
| stepper                                                       | `bulud-ng/stepper`: projected steps, native buttons; no assumed business progression                                              | disabled steps, selected content, keyboard activation                              |
| carousel/carousel-wrapper                                     | `bulud-ng/carousel`: projected slides + native previous/next, no autoplay                                                         | RTL, boundaries, labels, hidden slides                                             |
| timer-countdown                                               | `bulud-ng/countdown`: wall-clock countdown with cleanup                                                                           | restart/destroy, single completion, background drift                               |
| pipes + utility date/date-range/connection/password-generator | `bulud-ng/utilities`: pure pipes/helpers and SSR-safe injectable services                                                         | bad inputs, epoch zero, leap/month boundaries, listener cleanup, crypto randomness |
| avatar/profile/header-notification/platform-card              | Profile/logout/router/account coupled. Retain composition through existing initials/dropdown/dialog; don't import auth/profile UI | No backend/environment coupling                                                    |
| has-access/auth/account-state/error interceptor               | Domain roles, tokens/cookies, hardcoded APIs. Keep in consuming app                                                               | Don't transfer implicit auth/network side effects                                  |
| custom-cookie                                                 | Source forces itbfx domain and nested get bug. Browser cookie policy belongs to app; no copy                                      | No implicit cookie/domain ownership                                                |
| phone validation                                              | Depends on country models; generic app must provide its own numbering policy                                                      | No incomplete universal-phone regex                                                |
| charts                                                        | ApexCharts/financial chart dependencies; excluded from dependency-free shared transfer                                            | New chart package requires an explicit dependency decision                         |
| month/year picker                                             | Existing Datepicker handles date navigation; standalone month-only selection remains separate work                                | Don't claim a date-only value is a month value                                     |
| input-mask/numbers/max-length/English keyboard                | Prefer native inputmode/pattern/maxlength + existing digits and Angular validators                                                | Don't break IME/paste/accessibility by filtering keystrokes                        |
| language/theme switches                                       | Already owned by base preferences, library reads injected locale/ancestor theme                                                   | Library never changes app routing/lang itself                                      |

Implementation order: URL/filter correctness, table semantics, forms, then supporting primitives. New UI must use signals/OnPush, standalone secondary exports, CSS variable fallbacks and typed theme overrides. Demos are lazy-loaded to preserve initial bundle budget. No new dependencies or Angour source edits.
